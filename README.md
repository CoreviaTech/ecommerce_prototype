# HEDY ATELIER storefront concepts

A dependency-free set of responsive ecommerce concepts for a ceramics and gifting brand. Direction 01 now includes a connected Vietnamese storefront journey.

## Preview

Open any concept directly in a browser:

- `index.html` — Direction 01: Quiet Ritual
- `shop.html` — Direction 01 category and ritual-led shop index
- `collection.html` — Direction 01 collection listing with filters and sorting
- `product.html` — Direction 01 product detail, variants, gifting, and cart actions
- `direction-2.html` — Direction 02: Earthen Modernism
- `direction-3.html` — Direction 03: The Living Table / Gathered Forms
- `direction-4.html` — Direction 04: Small Joys / The Gift Note
- `direction-5.html` — Direction 05: Contemporary Folk / The Pattern Atlas
- `direction-6.html` — Direction 06: The Quiet Gallery / The Private Exhibition

Or serve the folder with any static server.

For example:

```powershell
npx serve .
```

Direction 01 includes responsive desktop/mobile layouts, category storytelling, collection filtering and sorting, product gallery and variant selection, a persistent prototype bag, gift-note entry, mobile navigation, search, Escape handling, add-to-bag feedback, and newsletter confirmation.

All prices, stock quantities, SKUs, dimensions, care details, delivery wording, and Zalo behavior in the prototype are illustrative content pending merchant approval and production data.
