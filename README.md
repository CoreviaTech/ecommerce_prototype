# HEDY ATELIER storefront concepts

A responsive, editorial ecommerce homepage concept for a ceramics and gifting brand.

## Preview

Open either concept directly in a browser:

- `index.html` — Direction 01: Quiet Ritual
- `direction-2.html` — Direction 02: Earthen Modernism

Or serve the folder with any static server.

For example:

```powershell
npx serve .
```

The concept includes responsive desktop/mobile layouts, collection storytelling, product interactions, a mobile menu, search overlay, add-to-bag feedback, and newsletter confirmation.
