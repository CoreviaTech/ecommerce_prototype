# Brand Intake

Use this reference when source identity, mood boards, palettes, or photography inform a visual direction.

## Audit Before Interpreting

1. Inventory relevant files and inspect image dimensions, formats, and actual content.
2. Separate verified inputs from interpretation. A photographic mood board is not an exact palette; a detailed logo lockup is not automatically a small-screen mark.
3. Check existing repository guidance before introducing names, taglines, provenance, audience claims, or color values.

## Translate References into Interface Decisions

- **Name hierarchy:** define compact, formal, and legal usage from supplied facts.
- **Logo behavior:** assess legibility at navigation, mobile, editorial, and footer sizes. Prefer a provided compact mark. If only a detailed raster exists, use a non-destructive crop or text companion without distorting the original, and retain the full lockup at a readable size.
- **Palette:** assign role-based working values such as surface, alternate surface, accent, text, and high-contrast field. Record that values are inferred when the source is photographic. Check text contrast and describe approximate color proportions.
- **Typography:** complement the identity rather than imitating lettering embedded in a raster logo. Keep interface text readable.
- **Photography:** define crop behavior, saturation, background treatment, and how mixed source imagery will feel coherent.

## Produce a Short Direction Brief

Capture: core idea, audience feeling, palette roles, type roles, layout principles, image treatment, motion character, and explicit differences from existing directions. Use it to evaluate later implementation decisions rather than as decorative copy.
